# 知物 1.1.21 · 首次公开发布

知物是一款本地优先的个人物品与订阅价值管理工具。它用拥有时间、日均成本和续费日程，帮助用户重新理解物品与持续服务的价值。

## 本次发布

- 物品日均持有成本、累计投入和拥有时间线
- 月付、年付、一次购买与免费服务管理
- 订阅续费和到期日程
- 物品与服务分类图标系统
- 浅色、深色与跟随系统主题
- JSON 备份恢复与 CSV 导出
- Web/PWA 与 Capacitor Android 工程
- 不依赖账号和远程业务后端的本地数据存储
- 中英文产品介绍、隐私说明和 AI 协作构建记录

## 在线体验

访问 <https://godiceman.github.io/zhiwu/>。首次打开会加载完全虚构的演示数据，可以在设置中清除。

> 数据保存在当前浏览器中。清理浏览器数据或更换设备前，请先导出 JSON 备份。

## Android

Android 源码与构建配置已包含在仓库中，并通过 Release 构建验证。为了不分发未经正式签名的安装包，本版本暂不附带 APK。

## English summary

Zhiwu 1.1.21 is the first public source release of a local-first value tracker for personal belongings and subscriptions. It includes the live PWA, the Capacitor Android project, privacy-safe demo data, automated tests, bilingual product documentation, and a transparent account of its human-led, AI-assisted delivery process. A signed Android binary is not attached to this release.
